# Orion SEO & Social — Google Sheets setup

## Import into one Google Sheet (multiple tabs)

1. Create a new Google Sheet: **Orion Metal — SEO & Marketing Ops**
2. For each CSV below: **File → Import → Upload** → select the CSV
3. Choose **Insert new sheet(s)** (not “Replace current sheet” after the first import)
4. Rename each imported tab to match the filename (without `.csv`)

| File | Tab name |
|------|----------|
| `01_Daily_Checklist.csv` | Daily Checklist |
| `02_Daily_Log.csv` | Daily Log |
| `03_Weekly_Checklist.csv` | Weekly Checklist |
| `04_Monthly_Checklist.csv` | Monthly Checklist |
| `05_Content_Calendar.csv` | Content Calendar |
| `06_Keyword_Tracker.csv` | Keyword Tracker |
| `07_NAP_and_Links.csv` | NAP & Links |
| `08_Leads_Log.csv` | Leads Log |
| `09_Monthly_Report.csv` | Monthly Report |
| `10_Access_Baseline.csv` | Access & Baseline |

## Daily use

- **Daily Checklist**: duplicate rows per weekday or use one row per day with Done? column
- **Daily Log**: one row per day (end of day)
- **Content Calendar**: plan posts and blogs; Status = Planned / Scheduled / Published
